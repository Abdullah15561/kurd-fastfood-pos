# 🍔 Kurd FastFood POS

A modern Point-of-Sale (POS) and restaurant management system designed for fast-food businesses.

## ✨ Features

- Point-of-Sale / Cashier System
- Product Management
- Inventory Management
- Order Management
- Table Management
- Customer Management
- Customer Debt Management
- Multiple Payment Methods
- Sales & Business Reports
- Admin, Manager & Cashier Roles
- English & Sorani Kurdish Support
- Responsive Interface

## 🛠️ Technologies

- Laravel
- PHP
- PostgreSQL
- Blade
- Tailwind CSS
- Alpine.js
- JavaScript
